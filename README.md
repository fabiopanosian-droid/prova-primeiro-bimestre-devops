# API de Reservas — DevOps

**Aluno:** Fábio Panosian
**RA:** 6325250

## Descrição

Projeto desenvolvido para a Prova do Primeiro Bimestre da disciplina de DevOps.

A solução consiste em uma API de Reservas desenvolvida em Node.js e Express, com persistência de dados em PostgreSQL, containerização com Docker, orquestração local com Docker Compose e infraestrutura na AWS provisionada com Terraform.

A infraestrutura utiliza módulos para VPC, Security Groups, EC2 e RDS, além de Remote State com S3 e DynamoDB, conforme os requisitos da prova.

## Tecnologias

- Node.js
- Express
- PostgreSQL
- Docker
- Docker Compose
- Terraform
- AWS
- Git/GitHub
